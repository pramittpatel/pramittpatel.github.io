# Pramit Patel · Portfolio

Personal portfolio of Pramit Patel, a Computer Science student at the
University of North Georgia focused on machine learning and applied AI.

**Live site:** https://pramittpatel.github.io/

## About this site

A static website written in plain HTML, CSS and JavaScript, with no framework
or build step, hosted on GitHub Pages. Project content lives in a single data
file, so adding a project doesn't require touching the page layout.

## Project structure

```
index.html            Page structure and content
css/styles.css        Styles and responsive layout
js/projects-data.js   Project list used to build the project cards and pages
js/main.js            Project rendering and navigation
js/effects.js         Optional visual effects (respects reduced-motion settings)
assets/               Resume PDF, profile photo, icon and project illustrations
MAINTENANCE.md        Guide for updating the site
```

## Run locally

```bash
python -m http.server 8000
```

Then open http://localhost:8000.
